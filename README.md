# UTracker – Credit (Utang) Management App

**UTracker** is a simple GUI-based application for managing credits or "utang" records. Built with **Python**, **Tkinter**, and **SQLite**, it allows users to track borrowers, record payments, and view transaction history—all in one place.

---

## 💡 Features

- 🔐 **Login system** (default: `admin` / `admin`)
- ➕ Add new credit entries (borrower's name, product, quantity, amount)
- 💰 Record payments and update balances
- 🔍 Search for borrowers
- 📋 View and edit transaction history
- 🗃️ Persistent data storage with SQLite
- 🖼️ User-friendly interface using Tkinter

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (for GUI)
- SQLite3 (for local database)
- ttk (Themed widgets)
